# 🚀 About

JARVIS-X is an AI-powered desktop assistant built using Python. It combines voice interaction, artificial intelligence, memory, and automation to create a smart desktop companion capable of assisting with everyday tasks.

This project is actively being developed and is designed with a modular architecture so new AI capabilities can be added over time.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/annukumarr/Jarvis-X.git
```

Move into the project

```bash
cd Jarvis-X
```

Create virtual environment

```bash
python -m venv venv
```

Activate environment

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run JARVIS-X

```bash
python main.py
```
